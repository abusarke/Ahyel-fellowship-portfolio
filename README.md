## 🛠️ Architecture & Technical Stack

The architecture focuses strictly on optimal performance, semantic structure, and native resource efficiency:

* **Structure (Semantic Layer):** Validated HTML5 markup ensuring robust SEO foundations, high accessibility (ARIA compliant), and intuitive DOM mapping.
* **Design System (Presentation Layer):** Modular CSS3 utilizing Custom Properties (`--variables`) for cohesive UI theme management, custom responsive layout grids, and optimized fluid typography breakpoints.
* **Interaction Engine (Behavioral Layer):** Event-driven Vanilla JavaScript implementing asynchronous layout states, fluid UI viewport transitions, and a state-managed, rule-based simulation engine for chatbot interaction.
